# FAT 长文件名

FAT12、FAT16、FAT32 和 LiveCD 的可写 FAT initramfs 共用 `kernel/fs/fat.c`。
目录枚举优先返回 VFAT 长名，查找同时接受长名和磁盘中的 8.3 别名。创建文件、
创建目录、同目录重命名及删除使用同一套名字和目录槽处理。FAT32 根目录与子目录
均沿完整簇链读取和增长；FAT12/16 固定根目录耗尽时返回空间不足。

磁盘 LFN 为 UTF-16LE，路径接口为 UTF-8，包括非 BMP 字符的代理对。
保留名字大小写，ASCII 查找不区分大小写；非 ASCII 按原字符匹配，不做 Unicode
大小写折叠或规范化。现有 VFS 名称字段为 255 字节（包括 NUL），因此可创建的
单个名字最多为 **254 个 UTF-8 字节**，同时不超过 VFAT 的 255 个 UTF-16 单元。
磁盘中超过 VFS 字节容量的名字通过短别名访问。i386 的执行字符集仍为 GB2312；
访问非 ASCII FAT 名字时，调用者须传 UTF-8 字节。

LFN 读取检查倒序编号、末项标记、属性、类型、首簇零值、短名校验和、终止符、
填充和 UTF-16 编码。损坏或不完整的组合回退到短名，不将其显示成伪造长名。
删除只回收与短名实际关联且合法的 LFN 槽。合法但超出 VFS 字节容量的组合仍能
经短别名删除并回收全部槽。非法 UTF-8、控制字符、VFAT 禁用字符和末尾空格或点
在路径入口拒绝。

能用 8.3 及 NT 大小写标志表达的名字只占一个短目录项；混合大小写和长名写入
LFN。长名自动生成不冲突的 `~n` 别名。分配连续目录槽时跨扇区、跨簇搜索，复用
删除槽；同目录重命名尽量复用原组合。跨目录 rename 仍沿用现有驱动的
`VFS_ERROR_NOT_SUPPORTED` 行为。VFS 继续拒绝重命名打开文件及作为 cwd 的目录。

LiveCD 打包由 mtools 生成 LFN，不增加另一种 initramfs 文件系统。应用清单使用
原名；安装清单用 `source` 指定实际源短别名、`path` 指定目标原名，FAT/PFS 安装
均保留原名。DOSLDR 的启动文件仍可用固定短名访问。

## 验证

```sh
python3 scripts/test-x86_64.py --lfn --memory 3072 --timeout 180
python3 scripts/test-x86_64.py --arch i386 --lfn --memory 512 --timeout 180
python3 scripts/test-x86_64.py --firmware uefi --lfn --memory 3072 --timeout 180
```

该回归在 RAM 盘及临时 FAT12/16/32 IDE 磁盘上运行 `dktest.bin --lfn`。
覆盖长名读写和枚举、大小写、中文与 emoji、13 单元边界、254 字节边界、别名
碰撞、长短名互换、目录改名、跨簇分配及多次删除复用，也检查非法 UTF-8 和
禁用名字被拒绝，以及损坏 LFN 校验和时回退到短名。外部盘由 mtools 创建长名
和空文件，FAT32 根目录预先跨多个簇；系统修改后卸载重挂载核验，宿主再由 mtools
按长名提取写出文件并逐字节核验。脚本恢复启动配置并重建正常镜像。

上述 i386 BIOS、x86_64 BIOS/UEFI 回归均已通过；未执行交互安装器的完整磁盘安装流程。
