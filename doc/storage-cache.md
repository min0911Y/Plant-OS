# 文件读取与缓存

[开发指南](development.md) · [FAT](fat-lfn.md) · [AHCI](ahci.md)

普通文件读取和文件映射共用 VFS 页缓存，以挂载实例、节点身份和页号索引。
缓存跨描述符关闭和进程退出保留；删除、截断及卸载按既有 VFS 生命周期失效。
普通写入保持 write-through，底层成功后更新缓存；共享可写映射的同步仍通过
`msync`/`fsync` 下传文件系统和设备，不能用缓存命中掩盖设备错误。

## 批量读取

连续缺页一次最多读取 32 页（128 KiB），在已有缓存页或文件尾停止。
缓存页直接使用连续页分配所得的物理页，各页独立持有和释放，避免先读临时缓冲
再逐页复制。分配无法取得连续空间时缩小批次，单页分配失败时回收可淘汰缓存。
普通 `read` 和 `mmap` 使用同一填充路径；部分命中只读取缺失部分，不能整段
重读并覆盖已有共享映射的修改。文件末页的 EOF 后字节保持为零。

FAT 保留当前簇链的定位游标，使同一文件的向前读取从上一次位置继续。
换文件或向后读取重新定位；簇表修改时清除游标，不能把截断前的位置用于复用
后的簇链。连续簇仍合并成扇区请求，碎片处拆分，由块设备层根据驱动能力分批。

文件扩容优先从链尾之后寻找空闲簇，绕回盘头后最多扫描一圈；只将旧链尾和
新增簇对应的 FAT 连续范围写回两份分配表，不能每次追加都重写整张 FAT。
普通文件分配簇时不预先清零整块：增长写入仅清零旧 EOF 到写入起点之间的
空洞，写入实际数据后才发布新长度；截断扩容仍清零全部新增可见范围。
目录的新簇在发布簇链前清零，保持目录项初始化语义。
复制程序使用 128 KiB 缓冲批量读写，成功前执行目标文件 `fsync`，并处理
短写、同步及两个描述符的关闭错误。

Legacy IDE ATA 每条 DMA 命令最多传输 256 个扇区（128 KiB），ATAPI 保持
64 KiB 上限。PRDT 按物理地址的 64 KiB 边界拆分，每次只初始化实际使用的
描述符；LBA28 的 256 扇区编码为零，LBA48 使用高低计数字节。
DMA 仍使用通道持有的缓冲和中断完成机制，不把用户缓冲直接交给硬件。
AHCI 保持端口自己的传输上限，同样接收上层合并后的读取。

IDE 普通写入等待 DMA 完成，将数据交给设备缓存；通过块设备 `Sync` 接口
在 `fsync`、`msync` 和关机时发送 `FLUSH CACHE`，不在每条 DMA 写命令后刷盘。
根据 IDENTIFY 的有效能力位选择普通或扩展刷盘命令；启用了写缓存却无法
刷盘的设备不予注册。同步与 DMA 使用同一控制器锁，显式选择目标主/从盘，
以单调时钟限制等待并阻塞让出 CPU；错误上报 VFS，关机同步失败不得进入 S5。

## 缓存容量与映射

仅未被映射固定的页进入 LRU。首次映射摘出页，最后一次解除映射再放回；
固定页仍保留在哈希索引中，读写一致性和同步不依赖 LRU。
淘汰直接取 LRU 尾部，不扫描活动映射，避免大型映射加载时出现二次复杂度。

可回收缓存预算为物理内存的 1/8，最小 256 KiB、最大 256 MiB，计入页元数据。
页按需分配，不在启动时预留整个预算；活动文件映射所必需的页不计入此预算。
关闭大型文件后可在预算内保留内容，重复启动程序可以复用这些页。

## 验证

两种架构的 `--dynamic` 覆盖跨多个批次且含局部缓存命中的映射、末页清零、
共享/私有映射、普通读写一致性、并发映射和部分解除映射。
`--lfn` 中的 `CACHEIO PASS` 在 RAM 盘和 FAT12/16/32 IDE 盘上检查碎片链、
大块及非对齐读取、缓存命中、跨边界覆盖写、截断和再增长后的内容。
`python3 scripts/test-file-copy.py --out /tmp/plant-copy --accel kvm` 在独立的
FAT32 磁盘内复制原版 MC JAR（或 `--source` 指定的文件），关机后核对源文件、
目标文件的 SHA-256，并通过 QEMU 块统计限制写入量和小块请求数；客户机
单独记录复制命令耗时，启动、关机耗时另计。临时镜像自动删除。
同一脚本的 `--flush-error` 使用 QEMU blkdebug 注入刷盘错误，要求复制失败
且关机被拒绝；正常路径检查复制同步与关机的刷盘次数，不能通过省略持久化
操作提高测试成绩。
`--ahci --machine q35` 继续验证 SATA 读写、同步及介质内容。

OpenJDK 回归记录同一次开机中三次 `java --version` 的耗时，见
[OpenJDK](openjdk.md)。比较性能时固定 QEMU 加速器、CPU、内存和磁盘配置；
首次运行与缓存中的重复运行分别比较。
